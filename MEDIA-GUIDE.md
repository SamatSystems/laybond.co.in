# Media Guide — where your photos & videos go

The site is complete and works today. Every photo spot currently shows a dark branded placeholder with a small label.
**To fill a spot, save your photo with exactly the filename below.** No code changes are needed; the photo appears automatically.

## Quick rules
- **Format:** JPG (or WebP renamed per slot). Keep each image **under 300 KB**. Use https://squoosh.app (free) at quality ~75.
- **Filenames:** lowercase, exactly as listed. `Tanks.JPG` will NOT match `tanks.jpg`.
- **Landscape vs portrait:** sizes below are recommendations; images are cropped to fit automatically (centre-weighted).
- Hero images get a dark overlay so text stays readable, so bright photos work well.

## Videos
| File | What | Spec |

Tip: compress with HandBrake (free), preset "Web > Vimeo YouTube 720p30", and tick "Web Optimized".

## Gallery (unlimited photos)
The gallery is driven by **`assets/js/gallery-data.js`**. Open it in any text editor (Notepad / TextEdit):
1. Copy photos into `assets/images/gallery/` (about 1600 px wide).
2. Add one line per photo, e.g.
   `{ src: "assets/images/gallery/hcl-tank-2025.jpg", title: "30 m³ HCl tank – Chennai", category: "tanks" },`
3. Categories: `tanks`, `acid`, `scrubbers`, `piping`, `linings`, `fabrication`, `site`.
4. Add `featured: true` to show it on the Home page (first 6 featured are used), and `wide: true` for a double-width tile.
The file already contains 16 example entries. Rename your files to match them, or replace the list.
